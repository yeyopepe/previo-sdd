# Planes y análisis

## Reglas de oro

### Cuando analicemos un problema o propuesta...
- Cuando analicemos un problema o propuesta y se pida escribirlo o anotarlo, se escribe como un plan en una subcarpeta dedicada dentro de `.claude/plans/`. Usa `/dev-analysis` para saber cómo escribir y estructurar el plan (carpeta con `PLAN.md` + `TASKS.md`) y qué hacer con él.
- Si te pido que analices un plan ya escrito, usa `/dev-analysis`.

### Después de implementar un plan...
- Después de implementar un plan tienes que revisar y actualizar cada documentación afectada (o preguntar si tienes dudas):
    - .claude/pv-doc/pv-design.md
    - .claude/pv-doc/pv-design-onescript.md
    - .claude/pv-doc/pv-install-scripts.md
    - .claude/pv-guide/pv-guide.es.md -> traducir con /en-translate
    - README.es.md -> traducir con /en-translate
