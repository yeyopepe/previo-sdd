# 013 — Etiquetas
**Area**: Gestión de componentes

Las etiquetas organizan y localizan componentes por nombre, con independencia de su tipo. Un componente puede pertenecer a varias etiquetas a la vez. Un panel flotante lista las etiquetas existentes, con el número de elementos de cada una y botones para editarla, eliminarla o crear una nueva.

Al hacer clic en una etiqueta se seleccionan de una vez todos los componentes que la llevan, incluidos los grupos etiquetados y las cartas guardadas dentro de un mazo (que se sacan del mazo a la mesa para poder seleccionarlas). Las etiquetas se asignan desde el menú contextual de la selección o desde la ventana de edición de la etiqueta, que lista sus elementos y permite quitarlos uno a uno.

Eliminar una etiqueta que está en uso muestra una ventana con los componentes y grupos afectados antes de confirmar; al borrarla se retira de todos ellos.
