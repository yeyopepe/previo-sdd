# 030 — Conversión automática a WebP
**Area**: Recursos e imágenes

Al subir una imagen en formato PNG o JPG se convierte automáticamente a WebP, sin pérdida perceptible de calidad. Así el fichero final del juego (guardado y exportado) se mantiene ligero.

Las imágenes que ya vienen en un formato comprimido (GIF, SVG, WebP) se guardan tal cual.

- **Available in**: Modo edición (al subir imágenes a la galería)
