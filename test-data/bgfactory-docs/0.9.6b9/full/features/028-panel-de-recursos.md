# 028 — Panel de recursos
**Area**: Recursos e imágenes

Un panel flotante independiente lista en tabla la galería de recursos del juego: imágenes y tipografías. Cada fila muestra el nombre del recurso, cuántos componentes lo usan y botones para editarlo o eliminarlo.

El panel se arrastra, se colapsa y se redimensiona igual que el de componentes, y su estado se recuerda entre sesiones. Una caja de filtro de texto acota la lista por nombre.
