# 001 — Mesa de juego infinita
**Area**: Mesa y navegación

La aplicación presenta una única mesa de trabajo virtual de tamaño ilimitado sobre la que se colocan todos los componentes del juego. El usuario navega libremente por ella arrastrando el fondo con el ratón para desplazarse y usando la rueda del ratón para acercar o alejar la vista.

La mesa muestra un fondo gris con una retícula de puntos que ayuda a percibir el desplazamiento y la escala. Al desplazarse o cambiar el zoom solo cambia la porción visible y la ampliación de la vista: la posición y el tamaño reales de cada componente sobre la mesa no se ven afectados.

La misma mesa se emplea en los dos modos de la aplicación: en modo edición los componentes son seleccionables y editables; en modo juego están listos para interactuar con ellos.
