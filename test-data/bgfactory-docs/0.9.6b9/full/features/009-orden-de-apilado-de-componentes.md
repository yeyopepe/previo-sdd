# 009 — Orden de apilado de componentes
**Area**: Gestión de componentes

Cada componente tiene un número de orden que determina qué pieza queda por delante de cuál cuando se solapan en la mesa. El orden se edita directamente en la columna correspondiente del panel de componentes, tecleando el número deseado; el resto de componentes se recolocan para dejar hueco.

Los grupos se reordenan como un bloque contiguo: cambiar el orden de un grupo mueve todos sus miembros juntos, manteniéndolos consecutivos entre sí.

En modo juego, un componente configurado para subir al moverlo o interactuar con él pasa automáticamente al primer plano en cuanto se arrastra o se usa.

- **Available in**: Modo edición (columna de orden en el panel de componentes)
