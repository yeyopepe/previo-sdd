# 014 — Efecto de profundidad y extrusión 3D
**Area**: Gestión de componentes

Cualquier pieza puede recibir un efecto de volumen que simula grosor: un duplicado desplazado por detrás del componente que le da aspecto extruido. Se configuran el grosor del efecto y su color.

Si no se elige un color propio, se calcula automáticamente un tono coherente a partir del color base del componente (color del cuerpo del dado, del borde del tablero, del fondo de la carta, etc.).

- **Available in**: Modo edición (ventana de propiedades del componente, pestaña de visuales)
