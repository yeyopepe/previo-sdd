# 002 — Ajustar zoom para ver todos los elementos
**Area**: Mesa y navegación

Un botón recoloca y reajusta la vista de la mesa para que todos los componentes existentes queden encuadrados a la vez, con un margen alrededor. Es la forma rápida de reencontrar el contenido tras haberse alejado o desplazado lejos de él.

Si no hay ningún componente, la vista simplemente se centra.

- **Available in**: Modo edición (barra de herramientas) y modo juego (junto al botón de entrar en edición)
