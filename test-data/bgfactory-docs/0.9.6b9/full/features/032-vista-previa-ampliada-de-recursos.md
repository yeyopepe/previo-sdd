# 032 — Vista previa ampliada de recursos
**Area**: Recursos e imágenes

La ventana de edición de un recurso de imagen muestra una vista previa grande con controles de zoom y desplazamiento (pan) para examinar la imagen en detalle antes de usarla. El nivel de zoom se muestra numéricamente.

Para un recurso de tipografía, la vista previa muestra un texto de muestra escrito con esa fuente.

- **Available in**: Modo edición (ventana de edición de un recurso)
