# 019 — Interacciones programadas por componente
**Area**: Gestión de componentes

Para cada componente se decide qué puede hacer el jugador con él según el tipo de acción: clic izquierdo, doble clic, arrastrar y clic derecho. La pestaña de interacciones de la ventana de propiedades muestra qué hace cada acción en ese componente.

Los tipos con una interacción de clic izquierdo propia (lanzar el dado, voltear la carta, sacar la carta de arriba del mazo) permiten desactivarla, con lo que el clic izquierdo deja de hacer nada. El clic derecho es configurable entre no hacer nada o abrir el menú contextual.

- **Available in**: Modo edición (pestaña de interacciones de la ventana de propiedades); efecto en modo juego
