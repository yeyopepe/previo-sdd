# 023 — Dado
**Area**: Tipos de componente

El dado se configura con un número de caras (que genera los valores 1..N) o con una lista de valores personalizados separados por comas, numéricos o de texto. Se eligen el color del cuerpo, el color del resultado y una tipografía propia para el número.

En modo juego, el clic izquierdo lanza el dado con una animación y muestra un valor al azar entre los posibles; el doble clic abre el resultado a tamaño grande en una ventana. El resultado actual es estado propio del dado y no se sincroniza a sus copias.
