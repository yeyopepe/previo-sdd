# 016 — Tooltip de componente
**Area**: Gestión de componentes

Cada componente puede mostrar un tooltip propio al pasar el ratón por encima en modo juego, con un texto de ayuda libre. Sustituye al tooltip nativo del navegador y aparece sobre la pieza mientras el cursor está encima.

Los mazos nacen con un tooltip activado por defecto que indica cómo sacar la primera carta. El texto del tooltip admite las mismas variables dinámicas que el título de componente.

- **Available in**: Modo juego (al pasar el ratón por encima de la pieza); se configura en modo edición (pestaña de ayuda al jugador)
- **Code**: init
