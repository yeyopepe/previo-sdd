# 033 — Recursos de ejemplo por defecto
**Area**: Recursos e imágenes

En un primer arranque sin nada guardado, la galería se siembra con un conjunto de recursos de ejemplo para poder empezar a trastear sin tener que subir nada.

La siembra ocurre una sola vez: si el usuario borra a propósito esos recursos de ejemplo, no vuelven a aparecer en arranques posteriores.
