# 029 — Subida de recursos
**Area**: Recursos e imágenes

Se pueden subir recursos de tres formas: un único fichero, varios ficheros a la vez, o una carpeta completa. Los formatos admitidos son PNG, JPG, GIF, SVG y WebP para imágenes y TTF, OTF, WOFF y WOFF2 para tipografías; los ficheros de otro formato se descartan.

Al subir una carpeta solo se toman los ficheros del primer nivel; los que estén en subcarpetas se omiten y se informa de cuántos. Tras una subida en lote se muestra un resumen con los recursos añadidos, los reemplazados y los omitidos por formato.
