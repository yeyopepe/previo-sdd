# 027 — Visor de documentos
**Area**: Tipos de componente

El visor de documentos muestra un reglamento o una ayuda de referencia siempre a mano sobre la mesa. Su contenido puede ser texto o Markdown pegado directamente, o una página web externa embebida mediante su dirección.

El contenido en Markdown se convierte a texto con formato (encabezados, listas, listas de tareas con casillas, énfasis, enlaces). El HTML pegado se limpia de scripts y de manejadores de eventos antes de mostrarse. La hoja tiene fondo blanco, borde fino y barra de desplazamiento propia si el contenido no cabe.
