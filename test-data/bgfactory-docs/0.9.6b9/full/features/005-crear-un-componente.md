# 005 — Crear un componente
**Area**: Gestión de componentes

Al añadir un componente, primero se elige su tipo de una lista (carta, mazo, dado, tablero simple, tablero personalizado, cuadro de texto, visor de documentos). El componente nace con un tamaño y unas propiedades por defecto propias de ese tipo y aparece sobre la mesa con un ligero desplazamiento respecto al anterior para no solaparse.

Inmediatamente después se abre su ventana de propiedades para configurarlo. Si se cancela esa ventana, el componente recién creado se descarta.

- **Available in**: Modo edición (botón al pie del panel de componentes; menú contextual de la mesa)
