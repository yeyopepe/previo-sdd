# 020 — Portapapeles de estilos entre cartas
**Area**: Gestión de componentes

El estilo visual completo de una carta (sus dos caras: imágenes, formas, cuadros de texto, bordes) se puede copiar y pegar sobre otra carta para replicar su apariencia sin rehacerla.

El portapapeles vive solo durante la sesión del navegador y guarda un único estilo a la vez: cada copia sustituye por completo a la anterior. Nunca se guarda ni se incluye al exportar el juego.

- **Available in**: Modo edición (sección de estilo de la carta en su ventana de propiedades)
