# 021 — Carta
**Area**: Tipos de componente

La carta es una pieza rectangular con esquinas ligeramente redondeadas y proporción configurable: formatos predefinidos (póker vertical y horizontal, tarot, cuadrada, circular, hexagonal, triangular) o proporción libre.

Tiene dos caras independientes, frontal y trasera, que se editan a la vez en un editor visual: cada cara admite una imagen de fondo con ajuste de posición y zoom, formas geométricas y cuadros de texto con estilo propio (fuente, color, bordes, alineación y rotación libre). El contenido se dibuja a tamaño de píxel real.

En modo juego, el clic izquierdo voltea la carta con una animación y un breve efecto de confirmación; la cara mostrada es estado propio de cada carta y de cada copia. Una carta se puede meter en un mazo arrastrándola encima o desde su menú contextual.
