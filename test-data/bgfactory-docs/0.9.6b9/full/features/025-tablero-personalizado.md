# 025 — Tablero personalizado
**Area**: Tipos de componente

El tablero personalizado usa el mismo editor visual avanzado que las cartas: una única cara con imagen de fondo (con ajuste de posición, zoom y rotación), formas geométricas y cuadros de texto. Está pensado para tableros y mapas a medida, a tamaño de píxel real.

El borde puede ser biselado y llevar o no sombra de contacto, igual que el tablero simple.

- **Available in**: Modo edición (editor visual) y modo juego
