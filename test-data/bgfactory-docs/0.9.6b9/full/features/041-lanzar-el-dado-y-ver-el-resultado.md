# 041 — Lanzar el dado y ver el resultado
**Area**: Interacción en modo juego

En modo juego, el clic izquierdo sobre un dado lo lanza con una animación y muestra un valor al azar entre sus caras posibles. El doble clic abre el resultado a tamaño grande en una ventana, útil para que lo vean varios jugadores.

Si el dado está configurado para subir al primer plano al interactuar, se coloca por delante del resto de piezas al lanzarlo. Esta interacción de clic se puede desactivar por dado.
