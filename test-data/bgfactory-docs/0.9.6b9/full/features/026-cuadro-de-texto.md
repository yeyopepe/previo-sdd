# 026 — Cuadro de texto
**Area**: Tipos de componente

El cuadro de texto muestra texto libre directamente sobre la mesa, sin caja ni fondo, con una sombra sutil que mantiene la legibilidad sobre cualquier color de mesa. Admite formato enriquecido escrito en Markdown o en HTML.

En una sesión totalmente nueva se siembra un cuadro de texto de ejemplo junto con los recursos por defecto.

- **Available in**: Modo edición y modo juego (texto suelto sobre la mesa)
