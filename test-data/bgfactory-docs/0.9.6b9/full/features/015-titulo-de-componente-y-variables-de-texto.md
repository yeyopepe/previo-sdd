# 015 — Título de componente y variables de texto
**Area**: Gestión de componentes

Cada componente puede mostrar un título propio en una etiqueta anclada en su esquina superior, visible de forma permanente en modo juego mientras esté activada. Se configuran el texto, el color del texto, el color de fondo y su transparencia.

El texto admite variables dinámicas escritas entre llaves que se sustituyen en tiempo real por un valor calculado. La variable disponible para un mazo muestra cuántas cartas contiene en cada momento, siempre actualizada. Una variable que no aplica al tipo de componente se deja tal cual, sin sustituir.

- **Available in**: Modo juego (etiqueta sobre la pieza); se configura en modo edición (pestaña de ayuda al jugador)
