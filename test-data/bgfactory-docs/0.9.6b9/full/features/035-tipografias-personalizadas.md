# 035 — Tipografías personalizadas
**Area**: Recursos e imágenes

Se pueden subir fuentes propias (TTF, OTF, WOFF, WOFF2) a la galería de recursos y asignarlas al resultado de un dado o a los cuadros de texto de una carta.

Las fuentes se registran automáticamente al cargar el juego para que el texto que las usa se muestre correctamente desde el primer momento.

- **Available in**: Galería de recursos; se aplican al contenido de dados y textos de carta
