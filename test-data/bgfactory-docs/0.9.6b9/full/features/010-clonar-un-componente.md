# 010 — Clonar un componente
**Area**: Gestión de componentes

Clonar crea una copia independiente del componente, con toda su configuración, desplazada ligeramente sobre la mesa. El clon no queda vinculado al original: a partir de ese momento se edita por separado y los cambios en uno no afectan al otro.

El identificador del clon se deriva del original añadiendo un número entre paréntesis; los clones de un clon comparten la misma familia de identificador.

- **Available in**: Modo edición (panel de componentes y menú contextual)
