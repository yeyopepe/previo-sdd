# 024 — Exportar e importar selectivo

**Area**: Persistencia e intercambio

Exporta o importa componentes, recursos y etiquetas sueltos entre partidas en formato JSON, eligiendo exactamente que llevarse. Al importar se decide entre anadir a lo existente o sobrescribir, y como resolver los identificadores duplicados (sobrescribir o conservar ambos, renombrando el importado). Los nombres de etiqueta duplicados se renombran automaticamente.

- **Available in**: Barra de edicion (menus Exportar / Importar)
