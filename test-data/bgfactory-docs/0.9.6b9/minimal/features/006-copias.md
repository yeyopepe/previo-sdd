# 006 — Elementos "Copia" vinculados

**Area**: Editor

Crea copias vinculadas y sincronizadas con un componente original: al cambiar el original, todas sus copias se actualizan solas (tipo, nombre, imagen, tamano, titulo, tooltip, etiquetas, configuracion de diseno). El estado de interaccion propio de cada copia (resultado de dado, cara mostrada de carta) no se sincroniza. El bloqueo y la visibilidad pueden desincronizarse copia a copia. Al borrar el original se borran tambien todas sus copias.
