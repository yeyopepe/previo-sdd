# 027 — Autoguardado local y trabajo sin conexion

**Area**: Persistencia e intercambio

Mientras se trabaja, la partida se guarda automaticamente en el navegador tras cada cambio, sin accion del usuario. Una vez descargado el fichero, la aplicacion funciona completamente sin conexion. Si el navegador no puede guardar (cuota excedida u otro fallo), el autoguardado se omite en silencio sin interrumpir el uso.
