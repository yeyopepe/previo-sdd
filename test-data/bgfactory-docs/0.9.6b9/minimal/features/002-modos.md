# 002 — Modo edicion y modo juego

**Area**: Modo edicion y modo juego

Dos modos separados sobre la misma partida: el modo edicion muestra todos los paneles y controles de diseno para configurar componentes, propiedades, recursos y etiquetas; el modo juego permite interactuar con las piezas como jugador (tirar dados, robar y voltear cartas, mover fichas, ver tooltips) sin riesgo de tocar el diseno ni ver los paneles de edicion. El cambio entre ambos es instantaneo y no crea dos versiones distintas del estado.

- **Available in**: Selector de modo (cabecera y barra de edicion)
