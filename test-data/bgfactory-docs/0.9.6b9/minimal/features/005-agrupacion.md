# 005 — Agrupacion de elementos

**Area**: Editor

Agrupa varios componentes en una unidad con sus propias propiedades generales (bloqueo, visibilidad, tooltip, titulo, etiquetas), que mientras dure la agrupacion gobiernan el comportamiento en mesa por encima de las propiedades de cada miembro. El grupo se mueve, se selecciona y se edita como uno solo, y puede desagruparse en cualquier momento sin perdida de datos. Un grupo que queda con un solo miembro tras un borrado se disuelve automaticamente.
