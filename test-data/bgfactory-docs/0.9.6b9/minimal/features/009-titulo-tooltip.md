# 009 — Titulo y tooltip por componente

**Area**: Editor

Cada componente puede mostrar un titulo propio (con color de texto, color y transparencia de fondo) y un tooltip de ayuda al jugador con formato basico. Ambos admiten variables de texto dinamicas que se resuelven en tiempo real; por ejemplo `{cards_current}` muestra cuantas cartas quedan en un mazo, siempre actualizado. Una variable no aplicable al tipo de componente se deja literal, sin sustituir.

- **Available in**: Modo edicion (configuracion) y modo juego (visualizacion)
