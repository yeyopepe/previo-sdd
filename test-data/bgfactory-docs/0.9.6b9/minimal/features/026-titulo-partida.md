# 026 — Titulo de partida editable

**Area**: Persistencia e intercambio

El titulo de la partida se edita desde la cabecera y se usa como nombre de fichero por defecto al guardar o exportar. La version de la aplicacion se muestra siempre junto al titulo y en el pie, y no es editable.
