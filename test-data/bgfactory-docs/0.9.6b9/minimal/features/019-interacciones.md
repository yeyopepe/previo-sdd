# 019 — Interacciones programadas y bloqueo

**Area**: Componentes

Por cada componente se decide que puede hacer el jugador con el segun el tipo de accion (clic, doble clic, arrastrar, clic derecho); las interacciones propias de cada tipo (lanzar dado, voltear carta, sacar carta del mazo) pueden desactivarse individualmente. El movimiento se puede bloquear por componente o grupo con tres niveles (nunca, solo en modo juego, siempre), y una pieza puede ocultarse al publico en modo juego.
