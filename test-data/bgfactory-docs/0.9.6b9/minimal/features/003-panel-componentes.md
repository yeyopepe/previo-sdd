# 003 — Panel de componentes

**Area**: Editor

Panel flotante, arrastrable, colapsable y redimensionable, con el listado de todos los componentes en forma de tabla. Permite ordenar, filtrar y buscar por texto en cualquier columna, y editar, clonar, copiar, reordenar o eliminar cada componente desde su fila. La posicion, el tamano, el estado de colapso y los anchos de columna del panel se recuerdan entre sesiones.
