# 007 — Etiquetas

**Area**: Editor

Organiza y localiza componentes por nombre de etiqueta. Un componente puede pertenecer a varias etiquetas a la vez, y tambien un grupo puede estar etiquetado directamente. Desde el panel de etiquetas, seleccionar una etiqueta selecciona de un clic todos los elementos que la llevan, incluidas las cartas guardadas dentro de un mazo (que se sacan a la mesa al seleccionarlas). Al borrar una etiqueta en uso se pide confirmacion y se enumera lo afectado.
