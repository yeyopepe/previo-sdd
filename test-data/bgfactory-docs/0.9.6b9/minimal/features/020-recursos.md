# 020 — Galeria de recursos e imagenes

**Area**: Recursos

Panel de recursos independiente para subir imagenes y tipografias: de un fichero, de varios a la vez o de una carpeta completa (los ficheros en subcarpetas se omiten con aviso). Las imagenes PNG/JPG se convierten automaticamente a WebP para mantener el fichero final ligero. Detecta nombres duplicados y ofrece reemplazar, muestra un resumen final de la subida (anadidos, reemplazados, omitidos por formato) e incluye recursos de ejemplo desde el primer arranque.
