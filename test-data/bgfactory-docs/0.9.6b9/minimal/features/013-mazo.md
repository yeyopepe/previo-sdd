# 013 — Componente: Mazo

**Area**: Componentes

Pila ordenada y barajable de cartas, con una zona de revelado configurable (posicion respecto al mazo, texto, y cara mostrada al robar) e imagen propia de dorso. Permite barajar, ver el contenido, sacar una carta concreta (este donde este en la pila) y meter una carta en el mazo, arrastrandola encima o desde el menu contextual. Mientras una carta esta en un mazo no se dibuja como pieza independiente en la mesa.
