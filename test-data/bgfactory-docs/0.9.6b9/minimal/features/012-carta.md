# 012 — Componente: Carta

**Area**: Componentes

Editor visual de cartas con capas de imagenes, formas geometricas (circulo, cuadrado, redondeado) y cuadros de texto con estilo propio (fuente, color, bordes, alineacion, rotacion libre). Cada carta tiene dos caras independientes (frontal y trasera) con volteo animado, y una proporcion elegible entre once predefinidas (poker vertical/horizontal, tarot, cuadrada, circular, hexagonal en dos orientaciones, triangular normal e invertido) o libre. Las siluetas hexagonal y triangular se recortan con precision, incluido un borde interior de grosor uniforme.
