# 001 — Mesa de juego

**Area**: Mesa de juego

Mesa de juego infinita con navegacion libre mediante *pan* (arrastrar el fondo) y *zoom* (rueda del raton, centrado en el cursor). El nivel de zoom se limita entre 0,5x y 2,5x. Un boton "Ajustar zoom" reencuadra la vista para que todos los componentes quepan en pantalla. La posicion y el zoom de la camara se mantienen al cambiar de modo, pero se reinician al recargar la pagina.
