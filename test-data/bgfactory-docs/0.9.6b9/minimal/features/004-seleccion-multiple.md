# 004 — Seleccion multiple y movimiento en bloque

**Area**: Editor

Seleccion de varios componentes con Ctrl/Cmd+clic, que anade o quita elementos sin afectar al resto; un clic normal reemplaza la seleccion por un unico elemento. Los elementos seleccionados se mueven en bloque manteniendo sus distancias relativas, ya sea arrastrando o con las flechas del teclado (1 px, o 10 px con Mayusculas). El borrado de dos o mas elementos abre una confirmacion que enumera los afectados.
