# 022 — Galería de recursos e imágenes

**Area**: Recursos

Panel de recursos independiente para imágenes y tipografías, con subida de un fichero, de varios a la vez o de una carpeta completa. Detecta nombres duplicados y ofrece reemplazar, y muestra un resumen final de la subida (añadidos, reemplazados, omitidos por formato). Tiene vista previa ampliada con zoom y pan para encuadrar la imagen antes de usarla. Incluye recursos de ejemplo desde el primer arranque, que no se reponen si el usuario los borra a propósito. Avisa y bloquea al intentar borrar un recurso que sigue en uso por algún componente.
