# 009 — Atajos de teclado

**Area**: Interacción

Hay atajos de teclado globales que son equivalentes directos de botones ya existentes: ESC cancela el diálogo abierto, INTRO lo acepta, SUPR borra el componente seleccionado (en modo edición) y las flechas lo desplazan (en modo edición). No introducen acciones nuevas ni saltan confirmaciones.

- **Available in**: Toda la aplicación
- **Code**: init
