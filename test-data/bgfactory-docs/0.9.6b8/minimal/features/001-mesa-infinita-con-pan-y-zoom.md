# 001 — Mesa infinita con pan y zoom

**Area**: Mesa de juego

La superficie de trabajo principal de BG Factory es una mesa de juego sin límites sobre la que se colocan todos los componentes. Se navega libremente arrastrando para desplazarse (pan) y con la rueda para acercar o alejar (zoom). La posición y el nivel de zoom de la cámara se mantienen aunque la pantalla se redibuje por cualquier cambio. Un botón de "ajustar zoom" encuadra el contenido visible.
