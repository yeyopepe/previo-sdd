# 013 — Componente Carta

**Area**: Componentes de juego

Carta con editor visual: capas de imágenes, formas geométricas (círculo, cuadrado, redondeado) y cuadros de texto con estilo propio (fuente, color, bordes, alineación, rotación libre). Tiene dos caras independientes, frontal y trasera, con volteo animado. Admite proporciones predefinidas (póker, tarot, cuadrada, circular, hexagonal, triangular) o libres. En modo juego se voltea con clic.

- **Available in**: Modo edición (diseño) y modo juego (voltear)
