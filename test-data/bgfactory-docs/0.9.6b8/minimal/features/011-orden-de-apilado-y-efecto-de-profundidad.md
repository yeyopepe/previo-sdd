# 011 — Orden de apilado y efecto de profundidad

**Area**: Mesa de juego

Cada componente tiene un orden de apilado (z-index) sobre la mesa, ajustable individualmente o en bloque para grupos enteros. Además, cada pieza admite un efecto de profundidad o extrusión configurable (grosor y color) que le da volumen 3D.
