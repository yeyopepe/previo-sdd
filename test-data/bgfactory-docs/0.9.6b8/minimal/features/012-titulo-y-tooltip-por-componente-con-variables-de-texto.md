# 012 — Título y tooltip por componente con variables de texto

**Area**: Diseño de componentes

Cada componente puede mostrar un título visible (con color de texto, color de fondo y transparencia configurables) y un tooltip al pasar el ratón. Ambos textos admiten variables dinámicas entre llaves que se resuelven en tiempo real, como `{cards_current}` para mostrar cuántas cartas quedan en un mazo. El sistema de variables está pensado para ampliarse con nuevas variables sin rediseño.
