# 021 — Bloqueo de movimiento y ocultación de piezas

**Area**: Interacción

Cada componente o grupo tiene un bloqueo de movimiento configurable con tres valores: nunca, solo en modo juego, o siempre. Además, una pieza puede marcarse como oculta al público en modo juego.

- **Available in**: Modo edición (configuración) y modo juego (efecto)
