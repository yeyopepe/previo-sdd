# 020 — Interacciones programadas por componente

**Area**: Interacción

Cada componente y cada tipo de acción (clic, doble clic, arrastrar, clic derecho) tiene una interacción programada que decide qué puede hacer el jugador con esa pieza en modo juego. Las interacciones disponibles dependen del tipo de componente (lanzar un dado, voltear una carta, robar de un mazo), y se pueden desactivar individualmente por componente.

- **Available in**: Modo edición (configuración) y modo juego (efecto)
