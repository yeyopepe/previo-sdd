# 015 — Componente Dado

**Area**: Componentes de juego

Dado con número de caras configurable o una lista de valores personalizados (numéricos o de texto). Tiene tipografía propia para el resultado, animación de tirada, y un modal que muestra el resultado en grande al hacer doble clic. En modo juego se lanza con clic.

- **Available in**: Modo edición (diseño) y modo juego (lanzar, ver resultado)
