# 005 — Agrupación de componentes

**Area**: Modo edición

Varios componentes se pueden agrupar en una unidad con sus propias propiedades (bloqueo, visibilidad, tooltip, etiquetas). Un grupo se mueve y se edita como una sola pieza, y se puede desagrupar en cualquier momento sin perder nada. Si un grupo se queda con un solo miembro tras un borrado, se disuelve automáticamente. Las propiedades generales de un componente dentro de un grupo se resuelven combinando las suyas propias con las del grupo.
