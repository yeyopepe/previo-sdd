# 004 — Selección múltiple y edición en bloque

**Area**: Modo edición

Se pueden seleccionar varios componentes a la vez con Ctrl/Cmd+clic. La selección múltiple permite arrastrar todo el bloque manteniendo las distancias relativas entre piezas, ajustar en bloque el orden de apilado, y borrar de golpe con una confirmación previa.
