# 024 — Guardar y autoguardado local

**Area**: Persistencia

Mientras se trabaja, la partida se guarda automáticamente en el navegador (un único espacio por navegador y perfil), sin que el usuario tenga que hacer nada. La acción **Guardar** descarga una copia completa del editor con la partida embebida dentro: el propio fichero portable, listo para abrirlo en otro sitio y seguir jugando o editando sin conexión.

- **Available in**: Toda la aplicación
- **Code**: init
