# 008 — Menús contextuales por modo y tipo

**Area**: Interacción

El clic derecho abre un menú contextual con acciones específicas según el modo activo y el tipo de componente sobre el que se hace clic. Si el componente lo permite, ese mismo menú da acceso a acciones como clonar, copiar, eliminar, barajar un mazo o ver su contenido. Cada componente puede configurar qué hace su clic derecho (abrir el menú o ninguna acción).
