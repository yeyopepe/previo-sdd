# 006 — Elementos Copia vinculados

**Area**: Modo edición

Se pueden crear copias vinculadas y sincronizadas a un componente original: al cambiar el original, todas sus copias se actualizan solas (tipo, nombre, imagen, tamaño, etiquetas, interacciones y propiedades de diseño). El estado de interacción propio de cada copia (resultado de un dado, cara mostrada de una carta) no se sincroniza, y la posición de cada copia es independiente. El bloqueo y la ocultación se pueden desincronizar copia a copia. Al borrar el original se borran también todas sus copias. Las copias se distinguen visualmente con un contorno de selección rojo en lugar de azul.
