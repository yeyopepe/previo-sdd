# 007 — Etiquetas de componentes

**Area**: Modo edición

Las etiquetas organizan y localizan componentes por nombre, con independencia de su tipo. Con un clic sobre una etiqueta se seleccionan todos los elementos que la llevan, incluso si están guardados dentro de un mazo. Un componente puede llevar varias etiquetas. Al borrar una etiqueta en uso se avisa antes.
