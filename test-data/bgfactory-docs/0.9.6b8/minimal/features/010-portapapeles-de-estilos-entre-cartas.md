# 010 — Portapapeles de estilos entre cartas

**Area**: Diseño de componentes

Permite copiar la apariencia de una carta y pegarla sobre otra, para reutilizar el mismo estilo (fuente, colores, bordes, formas y cuadros de texto) sin rehacerlo. El portapapeles guarda un único estilo a la vez —el último copiado sustituye al anterior— y solo vive durante la sesión del navegador: no se guarda ni se incluye al exportar la partida.
