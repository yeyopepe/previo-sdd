# 003 — Panel flotante de componentes

**Area**: Modo edición

En modo edición hay un panel flotante, arrastrable, colapsable y redimensionable, con el listado de componentes en una tabla. Se puede ordenar por cualquier columna, filtrar y buscar por texto en cualquier columna. Desde el panel se selecciona una fila para editar o borrar ese componente. Existen paneles equivalentes para el listado de recursos y para el de etiquetas. La posición, tamaño y estado colapsado de cada panel se recuerdan entre sesiones.
