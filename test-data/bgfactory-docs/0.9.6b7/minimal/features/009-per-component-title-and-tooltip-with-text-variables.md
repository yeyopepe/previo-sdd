# 009 — Per-component title and tooltip with text variables

**Area**: Component styling

Each component can show an editable title and a tooltip. Both accept dynamic text variables (e.g. {cards_current} for the number of cards left in a deck), resolved live. The system is designed to grow with new variables.

- **Available in**: Edit mode and Play mode
