# 020 — Resource gallery with image upload

**Area**: Resources

A separate resources panel with upload of a single file, several at once, or a whole folder. Images are automatically converted to WebP on upload to keep the final file light. Duplicate names are detected with a replace option, and an upload summary reports added, replaced and format-skipped files. An enlarged preview with zoom and pan helps pick the right crop. Sample resources are included from the first run. Deleting a resource still in use by a component is blocked with a warning.
