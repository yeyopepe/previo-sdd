# 003 — Component panel with list, filter and sorting

**Area**: Component management

A floating, draggable, collapsible and resizable panel listing every component in a table (Id, Type, Actions). Each column can be filtered by free text and sorted, and its width adjusted. Rows can be selected, edited or deleted from here; grouped components are visually marked.
