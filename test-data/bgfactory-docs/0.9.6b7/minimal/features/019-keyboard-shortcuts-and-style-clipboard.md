# 019 — Keyboard shortcuts and style clipboard

**Area**: Interactions

Global keyboard shortcuts (ESC/Enter/Del/arrows) mapped to existing buttons and actions, plus a style clipboard to copy and paste appearance between components. The style clipboard lives only in memory for the session and is never saved or exported.
