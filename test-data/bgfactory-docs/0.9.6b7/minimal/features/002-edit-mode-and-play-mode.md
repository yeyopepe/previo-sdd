# 002 — Edit mode and Play mode

**Area**: Modes

Two separate ways of working on the same single game state. Edit mode shows every design panel and control to configure components, resources, tags and table layout. Play mode lets you interact with the game as a player - roll dice, draw and flip cards, move pieces, read tooltips - without design panels and without risking changes to the layout. Switching between modes is instant and never creates a second copy of the state.
