# 017 — Programmed interactions per component

**Area**: Interactions

Per component and per action type (click, double click, drag, right click), decide what the player is allowed to do with each piece. Movement lock is configurable per component or group (never / only in play mode / always), and pieces can be hidden from the audience in play mode.

- **Available in**: Edit mode and Play mode
