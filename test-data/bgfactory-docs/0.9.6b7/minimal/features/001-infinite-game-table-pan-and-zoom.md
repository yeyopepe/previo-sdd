# 001 — Infinite game table (pan and zoom)

**Area**: Game table

A boundless game table you navigate freely by panning and zooming, with a dotted-grid background. All components are placed and arranged directly on it. A "fit to content" control brings every piece back into view. The camera position is kept while you work in a session but resets on page reload.

- **Available in**: Edit mode and Play mode
