# 024 — Selective export and import

**Area**: Import / export

Move individual components, resources and tags between games as JSON, choosing exactly what to take. On import, choose between adding to what exists or overwriting, and how to resolve duplicate ids (overwrite or keep both). A detailed report is shown on id or reference conflicts.
