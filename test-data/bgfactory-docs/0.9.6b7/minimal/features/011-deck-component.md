# 011 — Deck component

**Area**: Game components

An ordered, shufflable pile of cards with a configurable reveal area (position, text, face shown when drawing), its own back image, and a menu to Shuffle, View contents, or Insert a card into the deck by dragging or from the context menu.

- **Available in**: Edit mode and Play mode
