# 010 — Card / token component

**Area**: Game components

A visual card editor with image layers, geometric shapes (circle, square, rounded) and text boxes with their own styling (font, colour, borders, alignment, free rotation). Two independent faces (front/back) with an animated flip. Predefined proportions (poker, tarot, square, circular, hexagonal, triangular) or free.

- **Available in**: Edit mode and Play mode
